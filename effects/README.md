# 🎥 Video Effects Showcase

This directory contains a collection of video effects and transitions that can be used to enhance your video projects. Below are the different types of effects available:

## 🎭 Logo Effects

1. **Cinematic Logo Intro** - A professional, high-impact logo reveal with dynamic camera movements and lighting effects. [View Example](logo_effects/Cinematic_Intro_Controlled_Video_Generation.mp4)
2. **Particle Logo Animation** - Transform your logo into a mesmerizing particle effect that can be customized with different colors and behaviors. [View Example](logo_effects/particles_9_8_2025_7_03_44_PM_logo.mp4)
3. **Force Field Effect** - Create an energetic force field animation around your logo. [View Example](logo_effects/forceField_9_8_2025_10_48_59%20PM.mp4)
4. **Kaleidoscope Effect** - Turn your logo into a beautiful, symmetrical kaleidoscopic pattern. [View Example](logo_effects/kaleidoscope_9_8_2025_10_47_43%20PM.mp4)
5. **Shimmer Effect** - Add a subtle, elegant shimmer to make your logo sparkle. [View Example](logo_effects/shimmer_9_8_2025_10_35_26%20PM_logos.mp4)

## 🔄 Transitions

1. **Smooth Scene Transition** - Seamlessly blend between scenes with this elegant transition effect. [View Example](transitions/ComfyUI_00007_.mp4)
2. **Dynamic Wipe Transition** - Add energy to your edits with this dynamic wipe effect. [View Example](transitions/ComfyUI_00008_.mp4)
3. **Custom Transition Pack** - A collection of versatile transitions for various video editing needs. [View Example](transitions/comfyui-00002_j3RRy3uO.mp4)

## 🛠 How to Use

1. **For Logo Effects**: 
   - Place your logo file (PNG with transparency recommended) in the `logo_effects` directory
   - Run the respective effect script with your logo as input
   - Customize parameters like colors, duration, and animation style

2. **For Transitions**:
   - Use the provided Python scripts to apply transitions between your video clips
   - Adjust timing and easing functions to match your project's style

## 🎨 Customization

All effects can be customized by modifying the source files. The code is well-documented to make adjustments easy.
