我们是什么公司 WHO WE ARE

我们不是卖 AI 画图工具的。客户交给我们的是一个需求，拿回去的是可以直接用的成品文件—— 设计稿、效果图、三视图、3D 模型、出厂文件、成片、教材包。 中间用什么模型、跑几轮，是我们的事。

01

设计

设计师出身美术学院。造型、配色、版式、纹样考据由人把关， AI 只是执行工具。所以出来的是设计稿，不是一张「还不错的生成图」。

→ 方向板 · 设计稿 · 视觉体系
02

AI 生产系统

核心工程团队做了十几年大型机器学习与推荐系统。我们把模型包进 可重复、可约束、可追溯的流水线：同一套风格引擎批量铺 SKU， 一致性由系统保证。

→ 批量 · 一致 · 可返工
03

落地

做到能交工厂那一步：三视图带尺寸、刀线带出血、白墨单独出版、 色号给 Pantone。设计交付不等于生产交付，我们把后半段也接了。

→ 出厂文件 · 打样跟进
为什么这三样必须在一家 这三年我们见过两种失败。纯 AI 团队出的东西「AI 味重」——线条飘、纹样瞎编、 四个一套的东西比例各跑各的，客户说不出哪里不对但就是不敢用； 纯设计团队做得好看，但一款一款画，客户要三十个 SKU 就报不起价、也赶不上档期。
我们的做法是让设计定标准、让系统做量：设计师定死造型语言、配色、比例基准和线条质量， 然后由流水线批量执行并逐张对标。所以我们既敢接「一个系列三十款」， 也敢把稿子直接发给工厂。

案例一

城市文创插画 · Q 版上海限定

一套引擎 → N 个城市
上海 6 景一套：外滩 · 陆家嘴 · 豫园 · 武康大楼 · 石库门 · 上海味道。 双语标签、微笑云、暖秋银杏色板，以及一只贯穿每一格的弄堂三花猫—— 这是这个品类的签名装置，也是「成套」的视觉锚点。用于陶瓷冰箱贴、明信片、贴纸。
v1 满细节 → AI 味重，5cm 上糊成一团
v2 极简 → 变成冷冰冰的矢量信息图
v3 加萌 → 线条细而「不实」，还是飘
v4 ✓ 暖色铅笔质感 + 实线条，手绘感立住
项目解析 这一页真正想讲的是「AI 味」是怎么被调掉的——四轮迭代，每轮换一个变量。 结论反直觉：问题不在细节多少，在线条实不实。 v1 减细节没用、v2 极简反而更冷、v3 加萌但线还是飘； 真正解决问题的是把「确信、连续、闭合、粗细一致的暖褐色实线」写成硬约束， 并明令禁止试探性 / 断续 / 双线 / 飘浮笔触。
另一个约束来自物理：成品磁贴只有 5cm，密而碎的线到那个尺寸一定糊。 所以画法不是审美偏好，是被产品尺寸倒逼出来的。
引擎做完之后，换城市只要换地标、换吉祥物、换色板—— 这就是文创品类能规模化的地方：一套风格引擎 × N 个城市 × M 个地标。

案例二

IP 衍生品与 3D · 从形象到工厂能报价的东西

吊坠 / 挂件 / 潮玩
概念设计稿 · 正视带尺寸 + 侧视 + 细节 + 材质工艺 + 链长
技术设计稿 · 四视 + A–A 剖面 + 逐项尺寸（自有 IP）
三视工作表 · 尺寸带由代码写入，工厂据此报价
同一 IP × 八种工艺：亚克力挂坠 / 硅胶挂件 / 拼豆 / 3D 树脂 / 电镀金 / 软珐琅…各带正侧视、尺寸与工艺流程
亚克力出厂四版：正面印刷 / 镜像背面 / 白墨打底 / 刀线含吊孔
项目解析 IP 品牌手里通常只有一套平面形象。平面稿里没有侧面厚度、没有背面结构， 所以直接拿去建模就是猜——猜错一次，改模的钱比建模费本身还高。 我们的顺序固定：形象规范 → 转面图 → 带尺寸三视图 → 3D 模型 → 工艺深化 → 出厂文件， 每一步都有一个能拿给工厂看、也能被打回的交付物。
其中三视图是报价的钥匙：工厂可以凭一张标了尺寸的三视图报价、打样、开模， 却无法凭一张渲染图做任何事。所以它比 3D 模型更早交付—— 修一张图，比修一个模型便宜一个数量级。

项目解析 电商最贵的一段不是拍，是「一款要好几种图」：棚拍给比价用户、模特图给冲动购买、 场景图给种草、大片给投流。约一次摄影只能拿到其中一两种， 而且换季、换色、上新就要重来。
我们的做法是锁定商品本体，批量裂变场景与模特——同一双鞋，四种图一次出齐， 风格由同一套引擎约束，不会四张像四个品牌。右下两张是换装： 一张人像照片直接生成朝代服饰上身视频，用在文旅、剧集宣发和社媒都跑通过。

影像与视频 · 古风、品牌与产品动态

含多语言配音与字幕
古风 / 仙侠概念影像 —— 用于文旅宣传与剧情短片开场
同一世界观下的另一场景 —— 风格由同一套设定约束
天宫 · 长镜头

品牌工作流片 · 字体方案六款
产品短片 · 生活场景
项目解析 视频这条线有两种用法。一种是「拍不出来的」——天宫、云海、朝代场景， 实拍成本高到不现实，但文旅、剧集、品牌片又需要； 另一种是「拍得起但拍不完的」——品牌方案讲解、产品使用场景， 需要的是量和速度，不是电影级。这两种我们都做，用的是同一条流水线。
出海的部分单独说：整合了 语音识别 + 翻译 + 声音克隆配音 + 唇形同步， 一条中文片可以直接产出多语种版本，声音还是原来那个人的。 对做跨境的客户，这一段省掉的是重新配音和重新剪辑的整轮成本。

案例五

教育内容规模化 · 分级、双语、带配音

教材 / 课包 / 数字商品
HSK 2 · 黄粱一梦
HSK 3–4 · 欣怡的舞鞋
HSK 3 · 公主和小马
合体字识字卡 · 熊 + 猫 = 熊猫
同一版式换词即可复制
双语结构标注图 · 实物拆解认词
项目解析 教材类内容的痛点不是「做不出来」，是「一课一课做，做不完」。 一套 HSK 分级读物要几十篇课文，每篇都要课文 + 拼音 + 英译 + 配图 + 生词卡 + 朗读音频， 人工做一篇要一天。
我们把它拆成模板 + 数据：版式、分级规则、生词卡结构固定下来， 换文本就换一课，插图按课文情节生成，朗读用 TTS 出音频。 难点在中文本身——拼音标注要对、生词要卡在正确的 HSK 等级上、 插图不能跟课文情节打架，这几条都是有校验的，不靠模型自觉。
Curify AI案例五 · 教育内容08
怎么合作 HOW WE WORK

三种起手方式

  • 概念试案 —— 研究 + 2–3 个视觉方向 + 几款代表性产品图。用来定方向，成本最低。
  • 系列设计 —— 视觉体系 + 一个完整方向 + 8–10 款 SKU + 汇报 Deck + 两轮修改。
  • 设计 + 生产深化 —— 加上重点 SKU 的技术设计稿、3D、出厂文件与供应链对接。

我们需要你给的

  • 已有的 Logo / VI / 形象与配色，以及必须用或不能用的元素
  • 目标人群、客单价、想重点做的品类
  • 档期（展会、上新、开学季这类硬节点）

我们不做的事，也写清楚

  • 不出模具图纸。我们交三视图与 3D 模型，公差与模具结构由工厂工程师定。
  • 不在没有转面图的情况下硬猜 3D 形体——猜错赔的是一套模具。
  • 不用生成模型写图纸上的数字。数字由代码写入，来源可追溯。
  • 不改动客户已确认的IP 形象与品牌配色，只做工艺与量产翻译。
  • 非遗与文化纹样不编造。以客户官方资料或可考据来源为准。
最快的启动方式 挑一个最具代表性的单品，把「方向 → 设计稿 → 落地文件」全程走一遍。 一个跑通，剩下的是同一套约束的复制，风险和周期都可预期。
