# Curify portfolios moved

Finished Curify portfolio PDFs and collection boards are consolidated in [curify-gtm/curify_portfolios](https://github.com/super-inbox/curify-gtm/tree/codex/consolidate-portfolios-20261023/curify_portfolios).

Use the category index or offline search page there. Exact duplicates were merged; historical variants remain in `archive/`. The manifest maps every original file to its verified destination. Production sources, client proposals, financial documents and third-party reference materials remain here.

The deck and print builders now write to the canonical library. With sibling checkouts this resolves automatically; elsewhere set `CURIFY_PORTFOLIOS` to the library directory.
