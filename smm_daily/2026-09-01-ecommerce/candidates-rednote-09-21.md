# 一、这五篇教了什么

| 帖 | 数据 | 形制 |
|---|---|---|
| 电商美工必备！6 个超好用的设计网站 | **5345 赞** | 纯文字封面，四行巨字，三个小药丸（提升审美/收藏学习/提高效率） |
| 电商五张主图到底放什么？ | 2507 赞 · **2145 收藏** · 26 评 | 纯文字封面，问句，封面上直接印「点赞收藏+关注」 |
| AI 服装图的上限，由你的白底图决定 | 83 赞 · 34 收藏 · 21 评 | ❌误区 / ✅真相 对照，封面就是一张白底图 |
| 外贸人如何用 ChatGPT 生成产品图 | 356 赞 | 「4 种提示词 + 1 句关键提醒」，封面画出 prompt → 四种成品图的流程 |
| 亚马逊 A+ 大卖质感图怎么来的？ | 45 赞 | 问句 + 一张高完成度卖点图 |

**六条可直接照抄的形制：**

1. ⭐ **纯文字封面最猛。** 两篇最高的（5345、2507）封面上一张产品图都没有，就是巨字加渐变。
   带成品图的三篇是 356 / 83 / 45。**我们自己那两张卡（`rn-服装1`、`rn-服装2`）信息量偏大，
   要往「四行巨字」收。**
2. **标题里必须有数字。** 6 个网站 / 五张主图 / 4 种提示词 + 1 句提醒。
3. **前两到四个字点名买家。** 电商美工、外贸人、亚马逊 —— 不是「你」，是他的职业名。
4. **问句开头。** 到底放什么？怎么来的？ 疑问句比陈述句省一次说服。
5. ⭐ **收藏≈点赞（2145/2507）说明这是工具贴。** 买家是存下来当参考，不是看个乐。
   所以内容要**可对照执行**，不要抒情。
6. **提示词本身就是钩子。** 「4 种常用产品图提示词」直接换收藏；
   那篇的「猜你想搜」是**衣服白底图ai口令**。

**两条词汇发现，比形制更重要：**

- 🔑 **成品图有一套行业叫法，我们一直没用：白底图 / 卖点图 / 社媒图 / Banner图 / 主图 /
  SKU图 / 详情页。** 我们英文那边说「six frames」，中文这边就该说这几个词。
  买家是按这几个词搜的（「猜你想搜：电商主图与SKU图的区别」）。
- 🔑 **他们的失败词和我们的一模一样**：那篇白底图讲「AI 不会把**领口、袖口**画崩」——
  和我们 A2 / 电商验收里的词完全对上。说明这套语言是对的，不用另造。

**两条战术观察：**

- 「电商五张主图到底放什么？」**就是我们 A7 / 服装-2 的内容**，它拿了 2145 收藏。
  选题被验证了，我们的问题只是**封面和标题没按这个形制走**。
- 那篇底下 **CurifyAI 设计已经留过评论**（批量生图生视频 · 先试图满意再批量 · 私信即可），
  同一楼里还有同行带着截图在抢。评论区截流这条路是活的，也已经有人在抢同一批帖。

# 二、候选（8 条）

_每条都标了**用我们哪个现成资产**。⛔ 全部只发方法，不发客户图、不出现款号或对方名称。_

## C1 · 服装五张主图，到底放哪五张？

**为什么**：对标 2145 收藏那篇，但它讲通用电商，**我们讲服装**，而且能答得更具体。
**封面**：纯文字四行 —— 「服装五张主图 / 到底放 / 哪五张？」+ 药丸「收藏对照用」。
**内容**：一张回答一个问题 —— 正面（款式门襟扣子）· 背面（后领背部结构）·
全身（衣长和松紧，买家就看这张）· 四分之三侧（侧面才看得清的结构）· 生活场景（氛围）。
**收尾**：五张里如果有两张回答的是同一个问题，你实际只交了四张。
**资产**：`agentic-adhoc/resources/fashion-materials/axes.json` →
`pose_expression.vocabulary.what_each_frame_answers`；服装-2 正文可复用。
**标签**：#电商运营 #主图设计 #服装电商 #主图技巧 #小红书电商 #爆款打造

## C2 · 白底图拍成什么样，AI 才不会把领口画崩

**为什么**：对标「AI 服装图的上限由白底图决定」，**但我们有他们没有的东西** ——
一份买家验收时真正会看的部位清单。
**封面**：一张干净白底平铺图 + 一行字。
**内容**：❌误区「随便拍一张，AI 能救回来」/ ✅真相。然后给**拍之前就要拍清楚的七个部位**：
纽扣 · 领口 · 面料 · 袖口 · 侧面 · 裤子纽扣 · 版型 —— 这七个是生成前先读一遍的，
读不清楚的地方，AI 就会自己编。
**再加一条他们没讲的**：模特身上有打底的原图不要用，那层会跟着进成品，整版作废。
**资产**：`axes.json` → `garment.extraction_fields` + `decorations_styling.inner_layer_bleed`；
FB 的 A2。
**标签**：#服装摄影 #白底图静物 #AI与摄影结合 #服装电商 #电商设计

## C3 · 4 句提示词 + 1 句关键提醒：白底图转模特图

**为什么**：提示词换收藏，是这批里最省力的转化。那篇「猜你想搜」直接是「衣服白底图ai口令」。
**封面**：prompt → 成品的流程图，四个成品格子标上 **白底图 / 模特图 / 场景图 / 详情页**。
**内容**：四句可直接抄的提示词（**用通用款式写，不用任何客户的版型**），
每句解释它在管什么。
**那 1 句关键提醒**：衣服的属性只能来自平铺图，模特参考只提供姿势、光线、背景和身形 ——
**这两样混在一起，是最常见也最贵的一种错**：宽松款会悄悄变修身，而买家量的就是胸围和衣长。
**资产**：`axes.json` → `generation_axes.governing_rule` + `garment.spec_shape`；
`design-agent-v0/tools/model-swap`。
⛔ 提示词必须重写成通用款，`spec.example.json` 里的具体版型不要外发。

## C4 · 为什么你那五张图，看起来像两次拍的

**为什么**：这批爆款里**没有人讲这个**，是差异化的一条。而且它专治「每张单看都好」。
**封面**：纯文字三行 + 一个小对照条。
**内容**：六张图里衣服全对，坏的那张是头发 —— 走路那张散着，其余盘着。
参考图带过来的不止姿势：头发、耳饰、手表、袖子挽没挽、鞋、包、指甲，整层跟着走。
**收尾给自检清单**（跟商品无关的那一层）。
**资产**：服装-3 正文现成；配图 `a6-outfit-itemised-minimalist.jpg`。
**注**：服装-3 已发或已排期，**这条是换封面和标题的二次发**，不是新写。

## C5 · 放大就崩：买家验收 AI 服装图的那一下

**为什么**：这批里没人讲「放大」这个动作，但它是买家真实的验收手势。
**封面**：一张细节微距（链条 / 扣子），一行字「他们会放大到这个程度」。
**内容**：买家原话是「不说一模一样，但放大一定程度不会崩」——
**这和缩略图上看着对，是两件事**。扣子数、镶口、链节、门襟，是放大后最先散架的地方。
可数的细节最不稳，但也最好查：数扣子，一秒钟的事，大多数人不做。
**资产**：`axes.json` → `acceptance_checks.zoom_robustness` +
`garment.closures.buyer_criterion`；配图 `a9-necklace-chain-detail.jpg`。

## C6 · 白底图、卖点图、场景图、详情页 —— 一个 SKU 到底要几张

**为什么**：**直接用行业叫法做标题**，这是买家搜索时用的词（「电商主图与SKU图的区别」
就是平台给的联想词）。属于「必备 + 数字」形制。
**封面**：四宫格，每格标一个叫法，中间一个 SKU。
**内容**：四种图各自在链路的哪一段、各自答什么、谁看。
**收尾**：大部分店卡在只有白底图和一张模特图，剩下两种从来没做过 ——
不是不想做，是场景图要外景、卖点图要设计。
**资产**：`nano-templates.json` → `template-fashion-ecommerce` 的七种处理
（studio / flat lay / editorial / street / lifestyle / moodboard / on-model）；
配图可用 `a7-one-sneaker-four-directions.jpg`（同一双鞋四种处理）。

## C7 · 预览图是干净的，原图多了一条开衩

**为什么**：标题本身就是完整的故事，不需要解释。这批爆款里也没有人讲交付分辨率。
**封面**：纯文字两行，字越大越好。
**内容**：三个在原图尺寸才看得见的问题，最贵的那个不是瑕疵，
是**一个不存在的款式特征** —— 发出去买家收到的裙子没有开衩，那是货不对版，
而且以退货的形式回来。最后那道出大图是**又生成了一次，不是放大**。
**资产**：服装-4 正文现成；配图 `a9-jewelry-flatlay-detail.jpg`。
**注**：同 C4，这条是**换标题的二次发**。原标题「要看原图，不要看预览图」是陈述句，
这个标题是场景，按这批的规律更抓人。

## C8 · 电商美工必备：服装 AI 出图的 7 个验收点（买家自己排的序）

**为什么**：套 5345 赞那篇的「**电商美工必备 + 数字**」形制，
而我们的内容比「6 个设计网站」硬 —— 这七条是买家在看到任何图之前就写下来的。
**封面**：纯文字四行巨字，「电商美工 / 必备 / 服装AI / 7个验收点」+ 三个药丸。
**内容**：七类，按买家自己的排序。**第一条是货不对版，不是好不好看** —— 排序本身就是论点。
**资产**：服装-1 正文现成；`axes.json` → `buyer_rejection_taxonomy`。
**注**：服装-1 已发（09-20）。**这条是换封面 + 换标题的二次发。**
原标题「服装 AI 出图的七类翻车」没有点名买家，也没有「必备」这个收藏钩子。
