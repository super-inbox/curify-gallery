# London · photo-to-camera-motion study

Both masters use the selected stabilized stairwell move and the same 16.90-second, 1080×1920, 60 fps edit.

| Master | Soundtrack |
| --- | --- |
| [A · Urban electronic](london-camera-motion-urban-electronic.mp4) | Monume, “Modern Futuristic Technology”, from the local music library |
| [D · Wakin Chau](london-camera-motion-wakin-chau.mp4) | 「難唸的經」, excerpt from the [Apple Music preview](https://music.apple.com/us/song/1611719644). Public-use clearance is unverified. |

The edit moves from the Underground through the stairwell, the whale hall and the City, then through a sculpture opening to the Thames. The unobstructed Thames view was completed with ImageGen using the source photo as reference. Source photographs are kept locally in `../london-photo/`.

The retouching queue lists this as V2 after the stadium reference, with A as the lead version and D as an alternate.
